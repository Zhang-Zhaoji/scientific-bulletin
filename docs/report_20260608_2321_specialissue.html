Summary 具身智能：从传统机器人到VLA与AI for Neuroscience

一、传统机器人学：模块化的工程智慧

传统机器人系统遵循严格的模块化设计范式，形成一条经典的感知-规划-控制流水线：

1. 感知与建图（SLAM） - SLAM（Simultaneous Localization and Mapping）：通过视觉或激光雷达提取环境特征，构建三维点云地图，同时确定自身位置 - 核心价值：建立内部世界模型（Internal Model），使机器人能够区分已探索与未探索区域，实现高效路径规划（如扫地机器人的全覆盖清扫策略）

2. 运动规划 - A*算法：在离散图上引入启发函数（heuristic）加速最短路径搜索，保证最优性的同时减少无效探索 - RRT（Rapidly-exploring Random Tree）：面向连续空间与避障需求的随机采样方法，支持双向RRT、RRT*等改进版本，适用于机械臂关节空间规划

3. 执行控制 - 正向运动学（Forward Kinematics）：由关节角θ₁,θ₂,θ₃计算末端执行器位置，解析解简单直接 - 反向运动学（Inverse Kinematics, IK）：由目标末端位置反求关节角，存在多解性与冗余自由度，需引入光滑性约束或优化准则 - STAC：将目标位置作为约束进行贝叶斯估计，与IK求解目标一致但直觉不同 - PID控制：经典的反馈控制算法，驱动电机实现期望轨迹跟踪

核心局限：高度特化（Specialization），每个任务需人工设计专用管线，缺乏跨任务泛化能力；环境参数变化（如体操垫高度）即可导致失效。

二、VLA纪元：数据驱动的通用机器人智能

VLA（Vision-Language-Action）将大语言模型的推理能力引入机器人控制，追求"通用性"而非"特化"：

2.1 早期探索：SayCan（Google）

  • 核心思想：双重打分机制——Language Score（指令合理性）× Affordance Score（动作可执行性）
  • 局限：仅依赖初始语言描述进行一次性规划，无实时视觉反馈；执行依赖独立的行为克隆（Behavior Cloning, BC）模块

2.2 视觉融合：PaLM-E

  • 关键突破：将ViT视觉Token与语言Embedding共同输入大语言模型，实现每时间步的视觉感知
  • 优势：支持动态环境适应（如玉米片被移走后重新规划）、实时任务调整（如人类接手后停止放置）

2.3 端到端动作生成：RT-2

  • 创新：LLM直接输出动作Token（X/Y/Z位移与旋转），无需依赖独立的BC模块
  • 使用特殊Token（如1000以内数字或低频Token）编码连续动作空间，经IK映射为关节控制

2.4 高维动作生成：π₀ 与 Flow Matching

  • 架构：VLM（2.6B参数，如Gemma）处理多模态输入 → Action Expert生成动作块（Action Chunk）
  • Flow Matching技术：以ODE（常微分方程）替代Diffusion的SDE，在动作空间构造确定性向量场，实现高效高维运动规划
  • 现状：RT-2与π₀之后，VLA架构层面已无根本性突破，领域进入数据驱动时代

2.5 数据瓶颈与采集工厂

  • 模仿学习（Imitation Learning）主导：真实场景奖励函数难以定义，纯RL探索成本极高
  • 数采工厂：大规模人工遥操作（VR头显+手柄）采集真机数据，场景覆盖卧室、厨房、超市等
  • Foundation Model思想：VLM作为跨机器人平台的通用"大脑"，仅Action Expert需针对具体机器人微调

三、AI for Neuroscience：从虚拟生物到神经机制理解

3.1 虚拟啮齿动物（Virtual Rodent）

  • 构建带骨骼、蒙皮与关节电机的物理仿真小鼠，通过强化学习训练其在环境中执行任务（如触碰彩色球）
  • 局限：运动姿态不生物真实，难以作为神经科学研究的可靠模型

3.2 数据驱动仿生：MIMIC（Nature 2024）

  • 方法：6相机三维姿态估计 → 关键点标记（耳、鼻、肩、臀、四肢）→ IK骨骼配准 → 模仿学习训练策略网络
  • 价值：重建真实小鼠运动中的关节力矩，同步结合脑内电极记录，建立神经活动-运动参数的关联
  • 扩展：MIMIC-JAX实现GPU加速，推广至果蝇、线虫、竹节虫等多物种；支持肌肉骨骼模型（非纯关节电机）

3.3 生物物理精确模型：OpenWorm & BAAIWorm

  • 思路：基于线虫完整连接组（Connectome）与真实神经元模型（如LIF），模拟神经信号→肌肉激活→运动输出
  • 局限：确定性模型难以解释睡眠、衰老、疾病等复杂行为；行为 repertoire 有限

3.4 多模态整合：NeuroMechFly v2（Nature Methods）

  • 架构：视觉（六边形CNN处理复眼输入）+ 嗅觉 → 硅基神经网络解码 → Descending Steering Signal（低维控制信号）→ CPG网络 + 感觉反馈 → 运动执行
  • 权衡：未直接建模脊髓运动神经元，采用生物合理的中央模式发生器（CPG）降低控制维度，保证运动真实性

3.5 连接组学对接：果蝇全脑模拟

  • 基于13.9万神经元连接组与神经递质图谱，构建LIF神经元网络模型
  • 刺激特定感觉神经元（甜味/苦味/水）可产生对应的伸嘴等行为
  • 争议性工作（Eon System）：将连接组数据嵌入NeuroMechFly框架实现"虚拟果蝇"寻食，虽被批评过度宣传（"上传了果蝇"），但首次实现大规模连接组与生物物理模型的对接

四、Take Home Messages

范式 智能来源 核心特征 代表方法
传统机器人 人类工程（Engineering） 模块化、可解释、特化、确定性 SLAM, A*, RRT, IK, PID
VLA/强化学习 数据（Data） 泛化性、端到端、规模依赖、黑箱性 SayCan, PaLM-E, RT-2, π₀
系统与计算神经科学 生物理解（Understanding） 机制驱动、可解释、生物合理性、基础探索 MIMIC, Connectome, NeuroMechFly

核心洞察：

  1. 三条路径共享同一北极星：理解智能系统的本质，构建智能行为——无论是为了认识"我们是谁、从哪来、到哪去"，还是为了将人类从繁重/危险劳动中解放

  2. VLA的实用价值：在强辐射、外太空等人类难以直接介入的场景，本地部署的VLA机器人可替代传统需信号接口的自动化系统

  3. 神经科学的反哺意义：对生物智能机制的理解，可能为设计更高效、更节能的硅基智能系统提供灵感；费曼原则——"我不能创造的东西，我都不明白"——仍是检验理解深度的终极标准

  4. 当前阶段判断：VLA架构创新趋缓，进入数据Scaling时代；计算神经科学仍处于基础机制探索期，两者交叉融合是未来重要方向
