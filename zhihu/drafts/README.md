# 知乎待审草稿

此目录包含第 020–027 期的 18 篇 Markdown 分片和 8 张开篇统计图。所有分片按 Unicode 字符数和网页常见的 UTF-16 单元数两种口径，均不超过 100,000；每篇文章按完整的 `###` 子模块切分，未在单篇文献中间截断。原报告开头的 AI 编者提示、标题建议与“生成时间”已移除，文献自身的中英文标题保留。

## 导入与审阅

1. 按 `manifest.json` 中的日期及 `partNN` 顺序，在知乎“写文章”页选择“导入 → 导入文档”，逐篇导入 `.md` 文件。不要直接点击“发布”。
2. 第一篇开头的 `![本期文章发表统计](assets/stats_YYYYMMDD.png)` 是本地相对路径。导入后请检查图片是否被知乎实际上传并显示；如未显示，删除无效图片占位，在正文开头通过“图片”按钮上传同名 PNG。
3. 检查标题、表格、分片衔接和每期篇数，再决定是否发布。每个 `partNN` 是独立文章，建议按顺序发布并补上前后篇链接。
4. 不要把 `getfiles/summary_*.json` 的来源条目数解释为去重后的论文数。统计图中的“本期入选”来自原报告的推荐分类；来源排行是当期采集摘要的未去重条目数。

可运行 `python -B scripts/build_zhihu_drafts.py` 从原周报重新生成草稿、统计图和清单。该命令仅重建此目录的本地文件，不操作知乎网页，也不会发布内容。

浏览器自动导入已尝试，但当前浏览器控制权限拒绝选取本地文件。此目录的文件尚未通过自动化写入知乎草稿箱。
